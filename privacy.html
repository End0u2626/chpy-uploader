プライバシー ポリシー

chpy-uploader（以下「本ツール」）は、運用者本人が自身の YouTube チャンネル「End0uちゃん」へ動画を投稿するためだけに使用する個人用ツールです。本ツールが情報へアクセスするのは、運用者本人の Google アカウントとチャンネルだけです。

取得する情報と利用目的

本ツールは YouTube Data API を通じて、次のことを行います。

  • 運用者本人のチャンネル情報（チャンネル ID・チャンネル名）の読み取り：投稿先が本人のチャンネルであることを確認するため
  • 動画のアップロードとサムネイルの設定：本人のチャンネルへ動画を投稿するため

取得した情報を、上記の目的以外に使用することはありません。

保管と第三者提供

API の認可トークンは、運用者が管理する端末内にのみ保管します。取得した情報を第三者へ提供・販売することはありません。

認可の取り消し

Google アカウントの「サードパーティによるアクセス」の設定から、いつでも本ツールへの認可を取り消すことができます。取り消すと、本ツールは情報へアクセスできなくなります。
